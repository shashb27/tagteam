# M2 Implementation Guide — rollout ready

**Scope:** Docker deploy, session dashboard, a11y, mobile, load test, docs + announce. Still single-process.

## 1. Dockerfile

```dockerfile
FROM node:20-slim
WORKDIR /app
COPY package*.json ./
RUN npm ci --omit=dev
COPY server/ server/
COPY web/ web/
COPY docs/ docs/
ENV PORT=3000 DATA_DIR=/data
VOLUME /data
EXPOSE 3000
CMD ["node", "server/index.js"]
```

`docker-compose.yml`: one service, volumes `./data:/data`, `./logs:/logs`, env_file `.env`. `DEPLOY.md`: `docker compose up -d` → `http://localhost:3000`.

## 2. Session dashboard (`web/`)

New route `/dashboard` (client-side): lists the logged-in user's sessions (active + past) from `GET /api/sessions` (new, auth-scoped). One-click "resume" → WS-join with stored `resumeKey`. Cross-device: log in on Windows, see the session you started on Mac, resume it.

## 3. a11y + mobile

- Keyboard-only: every action reachable, focus visible, modal trap, escape closes.
- Screen reader: `aria-live` on transcript, `aria-label` on icon buttons, role=log on transcript.
- Contrast: AA (4.5:1) on all text; the current oxblood accent passes.
- Mobile: composer sticky, transcript scroll, participants collapse to a drawer <640px.

## 4. Load test

`test/load/autocannon.yml` — 200 concurrent WS connections, 10 sessions, 1 msg/sec each. Report: messages/sec, p99 latency, memory ceiling. Document the single-process limit in `docs/LOAD.md`.
